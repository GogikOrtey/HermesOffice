# Мелкие грабли агента

Временный журнал мелких трудностей окружения и нюансов (терминал, кодировки, таймауты, пути Windows и т.п.).
Не путать с `cursorcontext.md` — туда переносим только повторяющиеся (≥5) и важные для долгосрочной памяти.

## Правила ведения

1. При столкновении с мелкой проблемой — добавить запись или увеличить `Счётчик`.
2. Рядом писать краткое **Решение** (команда / приём / workaround).
3. Когда `Счётчик` достигает **5** — перенести описание + решение в `cursorcontext.md` (раздел «Грабли окружения»), здесь оставить пометку `→ перенесено в cursorcontext` и архивировать запись.
4. Не писать сюда продуктовые баги, roadmap и секреты.

Формат записи:

```
### Краткий заголовок
- Счётчик: N
- Симптом: …
- Решение: …
- Дата первого раза: YYYY-MM-DD
- Дата последнего раза: YYYY-MM-DD
```

## Активные

### electron-builder: EBUSY/EPERM на свежем exe
- Счётчик: 1
- Симптом: `electron-builder --win` падает с `EBUSY` на `HermesOffice.exe` (asar integrity / правка ресурсов) или `EPERM` при `rename` папки `.tmp` (распаковка Electron или кэш 7zip/NSIS). Воспроизводится и в каталоге OneDrive, и в `%LOCALAPPDATA%`.
- Решение: на время упаковки отключить антивирус реального времени; вывод класть вне OneDrive (`-c.directories.output` в `%LOCALAPPDATA%\hermesoffice-dist`). Застрявшие `*.tmp` в `%LOCALAPPDATA%\electron-builder\Cache` удалять через `cmd /c rmdir /s /q`. В PowerShell флаг `-c.directories.output=...` передавать в кавычках, иначе `-c` съедается.
- Дата первого раза: 2026-09-26
- Дата последнего раза: 2026-09-26
